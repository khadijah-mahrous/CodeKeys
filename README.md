# CodeKeys

**CodeKeys** is a full-stack web application that combines touch typing practice with programming language syntax learning. It offers structured typing courses for **Typing Basics**, **Python**, **JavaScript**, and **Java**. Users improve their typing speed (WPM) and accuracy while writing real code snippets and answering coding questions.

---

## ✨ Features

- **🎯 Typing Lessons** – Character‑by‑character exercises with immediate feedback.
- **🧠 Programming Exams** – Question‑based exams that test coding knowledge (including answer checking).
- **📈 Personal Dashboard** – Tracks your progress, best accuracy, and unlocks next lessons.
- **🏆 Achievements & Statistics** – Visual charts of WPM and accuracy history (last 7 days + lesson history).
- **🔐 User Accounts** – Sign up, log in, update profile, change password, or delete account.
- **📚 Multi‑language Support** – Four independent learning paths:  
  `Basics (touch typing)` | `Python` | `JavaScript` | `Java`
- **⭐ Star Ratings** – 0–5 stars based on lesson/exam accuracy.
- **⏱️ Real‑time Editor** – Modern code editor look with progress bar and live highlighting.

## 🛠️ Tech Stack

| Layer       | Technology                                                      |
|-------------|-----------------------------------------------------------------|
| Backend     | Python 3, Flask                                                 |
| Database    | SQLite (with `sqlite3`)                                         |
| Frontend    | HTML5, CSS3, JavaScript, Chart.js, FontAwesome (via emojis)     |
| Templating  | Jinja2                                                          |
| Auth        | Session‑based (no extra libraries)                              |
